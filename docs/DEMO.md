# سيناريو العرض · Demo scenario

مستشفى تجريبي جاهز (`npm run db:seed -w server`) فيه أسبوع شغل حقيقي: إسعاف فيه مرضى ناطرين، أسرّة مشغولة، وصفات وتحاليل ناطرة، مواعيد، وست شهور فواتير ومحاسبة. كلمة السر لكل الحسابات: **`Admin@12345`**.

## الحسابات · Accounts

| الدور        | الإيميل                 | ملاحظة                                                           |
| ------------ | ----------------------- | ---------------------------------------------------------------- |
| المدير       | `admin@nabd.demo`       | لوحة المستشفى، الموافقات، الأرباح، سجل النشاطات                  |
| الطبيب       | `doctor@nabd.demo`      | د. سامر الحلبي، القلبية، ورئيس القسم                             |
| طبيب استشاري | `dr.cardio.2@nabd.demo` | للاستشارات بين الأطباء                                           |
| طبيب إسعاف   | `dr.er.1@nabd.demo`     | بيستقبل استدعاءات الإسعاف                                        |
| ممرض إسعاف   | `rn.er.2@nabd.demo`     | التسجيل السريع وتقييم الخطورة وقائمة الانتظار                    |
| ممرض قسم     | `nurse@nabd.demo`       | أسرّة الداخلية: قبول ونقل وتخريج                                 |
| الصيدلي      | `pharmacist@nabd.demo`  | صرف الوصفات والمخزون، ورئيس الصيدلية                             |

| المنظف       | `cleaner@nabd.demo`     | التنظيف والتعقيم (وفي فرق لكل قسم: `cl.<قسم>.<رقم>@nabd.demo`)   |

وفي فرق لكل قسم: أطباء `dr.<قسم>.<رقم>`، ممرضين `rn.<قسم>.<رقم>`، ومنظفين `cl.<قسم>.<رقم>`، والأقسام: `er، or، internal، neuro، ortho، cardio، plastic، eye، gyn، lab، radiology، pharmacy`.

> نصيحة للعرض: افتح كل دور بنافذة متصفح خاصة (Incognito) أو بمتصفح مختلف، لتشوف الإشعارات والتحديث اللحظي بين الأدوار.

## العرض خطوة بخطوة · Walkthrough (حوالي 15 دقيقة)

### 1. المدير: المستشفى بنظرة وحدة

1. ادخل بـ `admin@nabd.demo`. الصفحة الرئيسية بتعرض: الموظفين ومين غايب اليوم، الطلبات الناطرة، الشكاوى، ربح الشهر، الأسرّة وغرف العمليات.
2. **الأرباح**: ربح كل شهر (الإيرادات ناقص المشتريات ناقص الرواتب)، واضغط على شهر لتشوف الإيرادات حسب القسم.
3. **الأقسام**: كل قسم إلو رئيس؛ غيّر رئيس قسم (طبيب منه، أو صيدلي للصيدلية).

### 2. الإسعاف: من الباب للطبيب

1. ادخل بـ `rn.er.2@nabd.demo` ← **حالة إسعافية جديدة**: سجّل مريض (أو "مجهول الهوية").
2. **تقييم الخطورة**: النبض والضغط والأكسجة والوعي والألم؛ النظام بيقترح مستوى ESI والممرض بيعتمده أو بيغيّره مع السبب.
3. المريض بيطلع بـ **قائمة الإسعاف** حسب الخطورة، وبيتحرّك لحاله على كل الشاشات.
4. **استدعاء طبيب**: اختار `د.` متفرّغ؛ إذا مشغول النظام بيقترح غيره من نفس الاختصاص.
5. بنافذة تانية ادخل بـ `dr.er.1@nabd.demo`: بيوصله إشعار عاجل مع صوت، بيقبل، والمريض بيصير من مرضاه.

### 3. الطبيب: الملف والطلبات

1. من **مرضاي** افتح المريض: الملف كامل (الحساسيات، التقارير، الوصفات، التحاليل، الصور).
2. اكتب **تقرير**، اطلب **تحاليل** (مثلاً CBC عاجل)، **صورة أشعة**، و**وصفة**.
3. **استشارة**: ابعت سؤال لطبيب تاني (`dr.cardio.2`)؛ بيشوف الملف وبيرد.

### 4. المخبر والأشعة والصيدلية

1. `lab@nabd.demo`: التحليل بيطلع بالقائمة (العاجل أول)؛ ابدأ واكتب النتيجة (مع PDF إذا بدك) ← الطبيب بيوصله إشعار.
2. `radiology@nabd.demo`: الصورة بتطلع لفني نفس النوع؛ ارفع الصور واكتب التقرير.
3. `pharmacist@nabd.demo`: الوصفة ناطرة؛ اصرفها من المخزون. إذا نزل صنف تحت الحد الأدنى بيوصل تنبيه.

### 5. القسم والأسرّة والتنظيف

1. `nurse@nabd.demo` ← **أسرّة القسم**: اقبل مريض على سرير فاضي، انقله، أو خرّجه.
2. التخريج بيحوّل السرير لـ "تنظيف" وبيبعت طلب لمنظفين القسم.
3. `cleaner@nabd.demo` ← **مهامي**: ابدأ وخلّص؛ السرير برجع فاضي بكل الشاشات.
4. **خريطة الأسرّة** (للمدير والأطباء): كل أسرّة المستشفى وحالتها لحظياً.

### 6. الاستقبال والمواعيد

1. `reception@nabd.demo` ← **تسجيل مريض**: مع حساب على نبض (كلمة السر بتطلع مرة وحدة) والحساسيات بتنحفظ بالملف.
2. **المواعيد**: احجز لمريض (قسم ← طبيب ← يوم ووقت)، وشوف مواعيد اليوم.
3. **تسجيل إسعافي سريع**، و**تعريف مريض مجهول** (إذا رقمه الوطني مسجّل، الملفين بيندمجو).

### 7. المحاسبة

1. كل خدمة أخدها المريض انضافت لحسابه لحالها بسعرها.
2. `accountant@nabd.demo` ← **الفواتير**: اختار مريض، اصدر فاتورة، واطبعها بشعار المستشفى.
3. **الدفعات**: سجّل دفعة كاملة أو جزء؛ الفاتورة بتتحدّث.
4. **لائحة الأسعار**: سعر لكل تحليل ولكل دوا، والمحاسب بيعدّلها.
5. **التقرير الشهري**: إيرادات الشهر للمدير.

### 8. المريض

1. `patient@nabd.demo`: الصفحة الرئيسية (موعدي الجاي، أدويتي، الباقي علي، نتائجي).
2. **ملفي الطبي** (مع طباعة PDF)، **مواعيدي** (حجز وإلغاء)، **أدويتي** (تذكير بكل جرعة، حتى والموقع مسكّر)، **فواتيري**، **شكاويي**.

### 9. الإدارة: الطلبات والرقابة

1. ممرض يطلب **إجازة** ← المدير يوافق ← رئيس قسم الممرض بيوصله "فلان غايب".
2. رئيس قسم (`pharmacist@nabd.demo`) بيطلب **شراء** النواقص أو **صيانة** جهاز ← المدير بيوافق أو بيرفض مع السبب.
3. **الشكاوى**: المدير بيرد والمريض بيقرأ الرد.
4. **الاجتماعات**: المدير بيطلب اجتماع مع طبيب، والطبيب بيوافق أو بيعتذر.
5. **سجل النشاطات**: مين فتح أو عدّل ملف أي مريض ومتى.

## أشياء تستحق تنشاف · Highlights

- **العربي والإنكليزي** (RTL/LTR) و**الوضع الليلي**، من القائمة فوق.
- **الموبايل**: كل الصفحات مرتّبة على عرض 320 بكسل؛ وفي **تثبيت كتطبيق** (PWA)، وإذا انقطع النت بتطلع صفحة "لا يوجد اتصال بالإنترنت".
- **العزل**: كل مستشفى بيشوف بياناته بس؛ في اختبار بيفتح كل صفحات المستشفى الأول وبيتأكد ما في ولا سجل من التاني.
